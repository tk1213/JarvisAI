# Contributor Guide

## Development Setup
- Python virtual environment
- Install requirements
- Configure .env

## Before Opening a PR
- Ruff passes
- Tests pass
- Live gate passes
- No debug code
- Documentation updated

## Commit Style
feat:
fix:
refactor:
test:
docs:
chore:

## Review Checklist
- Backward compatible
- Type hints
- Async safe
- Logging
- Error handling
- Tests added

## Definition of Done
- Feature implemented
- Documentation updated
- Gates pass
- Git clean
